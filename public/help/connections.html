Facebook & Instagram

The most involved setup of the four — Meta requires every app that publishes on someone's behalf to be registered through their developer platform. It's a one-time setup, not something you'll repeat.

1 Create the app

  1. Go to developers.facebook.com/apps and click Create App.
  2. Choose Business as the app type.
  3. Give it a name (e.g. "Blog Bunker") and your contact email, then select or create a Business Portfolio — your own is fine.

2 Add Facebook Login for Business

In the left sidebar, find Use cases and select or customize "Manage everything on your Page."

Inside that product's settings, find Valid OAuth Redirect URIs and add exactly this:

https://blogbunker.netlify.app/api/meta-callback
This must match exactly — no trailing slash, no trailing space. A mismatch here is the most common reason a connection silently fails.

3 Add Instagram publishing

Still under Use cases, add "Manage everything on Instagram". Choose "API setup with Facebook Login" — not "with Instagram Login."

Click "Add all required permissions", then confirm the full list matches:

pages_show_listpages_manage_postspages_read_engagement instagram_basicinstagram_content_publishbusiness_management

If pages_manage_posts isn't in the auto-added bundle, add it manually.

4 Add your Facebook Page to the app's Business Portfolio

This step trips people up more than any other.

  1. Go to business.facebook.com, in the same Business Portfolio your app is tied to.
  2. Go to Business Settings → Accounts → Pages → Add → Add a Page.
  3. Search for your Page and add it — you need Admin access to it.
Page not showing up when connecting? This is almost always why — the Page hasn't been added to the app's Business Portfolio, or your account only has Editor (not Admin) access.

5 Make sure Instagram can be linked

Needs to be a Business or Creator account, linked to the Page from step 4. Convert under Instagram's own Settings if it's currently personal.

6 Add testers

While in Development Mode (fine for a beta), add each tester under App roles → Roles — they'll accept a notification, then can connect immediately without full App Review.

7 Connect in Blog Bunker

Settings → Facebook & Instagram → Connect. If more than one Page is available, you'll be asked which one this workspace should post to.

Common questions

Can I use one Meta app for multiple workspaces or brands?

Yes. The app is just the credential — not tied to one Page. Connect a different Page per workspace with the same app; each workspace remembers its own choice.

Posts aren't showing up on Instagram — only Facebook.

Check the Instagram account is properly linked as Business/Creator (step 5), and that instagram_content_publish is actually granted (step 3).

Google Search Console

Lets Blog Bunker pull your real search performance data — clicks, impressions, and ranking keywords — right into Analytics.

Before you start: you need to already have your site verified in Search Console itself (at search.google.com/search-console) — this guide only covers connecting Blog Bunker to it, not the initial site verification.

1 Enable the API

  1. Go to Google Cloud Console and select (or create) a project.
  2. APIs & Services → Library → search for and enable Google Search Console API.

2 Create OAuth credentials

  1. APIs & Services → Credentials → Create Credentials → OAuth Client ID.
  2. Application type: Web application.
  3. Under Authorized Redirect URIs, add exactly:
https://blogbunker.netlify.app/api/gsc-callback

3 Connect

  1. Copy the generated Client ID and paste it into Blog Bunker's Search Console settings.
  2. In Netlify → Environment Variables, add GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET (from the same credentials screen), then redeploy.
  3. Back in Blog Bunker, click Sign in with Google.
Common questions

I signed in but no data shows up.

Search Console data has a natural 2-3 day reporting delay, and a brand-new site can take longer to accumulate meaningful data. Also confirm you signed in with the same Google account that has verified ownership of the site in Search Console.

Do I need a different Google Cloud project per workspace?

No — one set of credentials (Client ID/Secret) works for every workspace. Each workspace's actual Search Console connection (which site, which account) is kept separate.

WordPress

Publish directly to your own WordPress site — self-hosted or WordPress.com Business — right from the Article Pipeline. The simplest of the four connections: no OAuth, no developer app required.

1 Create an Application Password

This is a feature built into WordPress itself since version 5.6 — no plugin needed.

  1. In your WordPress admin, go to Users → Profile.
  2. Scroll to Application Passwords.
  3. Give it a name (e.g. "Blog Bunker") and click Add New Application Password.
  4. Copy the generated password immediately — WordPress only shows it once.
Use this generated password, not your regular login password — they're different, and your regular password won't work here.

2 Connect in Blog Bunker

Settings → WordPress → enter your site URL, your WordPress username, and the Application Password from step 1.

Common questions

My site URL isn't being accepted.

Make sure you're using the site's actual domain (e.g. yourblog.com), not a WordPress admin URL with /wp-admin or similar appended.

Does this work with WordPress.com's free plan?

Application Passwords require WordPress.com Business plan or higher, or a self-hosted WordPress install — the free/Personal/Premium WordPress.com tiers don't expose this feature.

Buffer (other social platforms)

Buffer handles the connection to X, TikTok, Pinterest, Reddit, Threads, Bluesky, YouTube, and Buffer's own Facebook/Instagram support — Blog Bunker only needs your Buffer API key, not a separate developer app for each platform.

1 Set up Buffer

  1. Sign up at buffer.com — the free plan works.
  2. Connect your social accounts inside Buffer itself (X, TikTok, Pinterest, etc.) — Buffer handles all of that platform-specific OAuth for you.

2 Get your API key

Go to buffer.com/api and generate an API key. You must be the organization owner to do this.

3 Connect in Blog Bunker

  1. Paste the API key into Settings → Buffer (Social) → click Load Channels.
  2. Map each Buffer channel to its matching platform.
  3. Save.
Common questions

A platform I connected in Buffer isn't showing up as a channel to map.

Confirm the account is actually fully connected and active inside Buffer itself first (not just started, but completed) — Blog Bunker can only map channels Buffer already reports as connected.

Is Buffer required, or can I skip it?

It's only needed for platforms beyond Facebook/Instagram (which connect directly, see above) and WordPress. If you only publish to those, you can skip Buffer entirely. Buffer access itself is available on Operative and above.

Still stuck on something not covered here? Use the Report a Bug button inside Blog Bunker and describe where you got stuck — that's the fastest way to get help.
